# Section 125 cafeteria plan tool — research record

**Template:** `s125-v1.0.0-2026-10-09`

**Status:** Educational sample for the employer’s own attorney and tax advisor. This record is not legal advice, and the generated plan is not adopted until the employer signs it.

The generator uses the points below. Dollar figures are the 2026 amounts locked on October 9, 2026. They are not guessed for later years.

| Point in the sample | Authority used |
|---|---|
| A cafeteria plan is adopted prospectively. The effective date must be today or later. | Code §125; 2007 proposed Treas. Reg. §1.125-1 (taxpayers may rely on the 2007 proposed cafeteria-plan regulations) |
| The plan year is 12 months. A short first year is used only when a new plan, or a restatement that changes the year, starts on a day other than the plan-year start. A restatement that keeps the year is not a short year. | 2007 proposed Treas. Reg. §1.125-1 (plan year) |
| February 29 is not offered as a plan-year start, so the date exists every year. The plan year ends the day before the next start. | Same 12-month plan-year rule |
| Open enrollment is the window ending the day before the next plan-year start on or after the effective date. If that window falls before the effective date, the sample calls it the enrollment to start the plan. | Plan design, tied to the plan-year start the employer chose |
| A missed election is a waiver and cash. It does not default to after-tax coverage. | 2007 proposed Treas. Reg. §1.125-2 (elections) |
| An election is effective when the chosen waiting period says coverage begins. The sample does not add an extra month. The 90-day choice is coverage on the 91st day. | Public Health Service Act §2708 (90-day maximum waiting period for group health plans) |
| Health FSA salary reduction for a plan year beginning in 2026 is $3,400. | Code §125(i); IR-2025-103; Rev. Proc. 2025-32 |
| Health FSA carryover from a plan year beginning in 2026 into the next plan year is $680. Amounts carried into a plan year beginning in 2026 from 2025 are $660. Grace period and carryover are not used together. | Notice 2013-71; IR-2025-103; Rev. Proc. 2025-32 |
| A grace period ends on the 15th day of the third month after the plan year. | Notice 2005-42 |
| Dependent care exclusion for 2026 is $7,500, or $3,750 if married filing separately. It is statutory, not an inflation figure in IR-2025-103. The 55 percent average-benefits test still applies. | Code §129, as amended by the One Big Beautiful Bill Act; Code §129(d) |
| Dependent care may be forfeited or given a grace period. The health FSA carryover does not apply to dependent care. | Notice 2013-71 (carryover is a health FSA rule) |
| The unused-funds rule is written in the plan. It is not left to side materials. | Code §125 written-plan requirement |
| A general-purpose health FSA and an HSA may both be offered. A person covered by the general-purpose FSA, and a spouse who can be reimbursed by it, is not an HSA-eligible individual. Limited-purpose coverage in this sample is dental, vision, and preventive care. A post-deductible FSA is the other HSA-compatible design and is named in the form note, not as a third plan option. | Code §223; Rev. Rul. 2004-45 |
| An HSA salary-reduction election can be changed or revoked prospectively at least monthly, without a change in status. Amounts already deposited are nonforfeitable. | 2007 proposed Treas. Reg. §1.125-2; Notice 2004-50, Q&A-58; Code §223(d)(1)(E) |
| For accident and health benefits, a child who has not attained age 27 as of the end of the taxable year can be covered even if the child is not a dependent under §152. Dependent care still follows §§129 and 21 and is generally under age 13. | Code §105(b); Notice 2010-38; Code §§129 and 21 |
| Partners, sole proprietors, members of an LLC taxed as a partnership or as a disregarded entity, and more-than-2% S corporation shareholders (with §318 attribution to a spouse, child, grandchild, or parent, and not to a sibling only) are excluded. There is no “owners participating” question. An LLC taxed as a C corporation does not use that exclusion. | Code §125(d); Code §401(c); Code §1372(b); Code §318 |
| A highly compensated individual under §125 owns more than 5 percent, not 5 percent or greater. The sample says the “or greater” wording is not the test. | Code §125(e) |
| Cafeteria-plan nondiscrimination tests apply at every size. Self-funded and level-funded medical benefits also face §105(h). At 50 or more employees the sample notes that FMLA may apply and that applicable-large-employer status depends on full-time equivalents, not headcount alone. | Code §125(b); Code §105(h); FMLA; Code §4980H |
| The employer is the plan administrator, acting through its authorized officer. The officer is not named personally as the fiduciary. The signature line and the date line stay blank. Severability is in every version. | Plan design for this educational sample |
| Eligible classes come from the form. “Other” is printed only with the description the employer types. Full-time and part-time use the weekly hours the employer enters. | Written-plan eligibility |
